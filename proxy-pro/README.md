# Math-X Proxy Pro

A full-featured educational web proxy interface for Math-X.

## Features
- Clean responsive interface
- URL navigation
- Search shortcut
- Back/forward/reload controls
- Favorites and history stored locally
- Settings panel
- Dark/light theme
- Keyboard shortcuts
- Loading and error states
- Privacy-friendly local storage
- Flask backend with SSRF protections

## Run
```bash
pip install -r requirements.txt
python app.py
```

Then open `http://127.0.0.1:5000`.

Use responsibly and only access sites you are permitted to access.
