The browser UI talks to a real Flask proxy server. HTTP/HTTPS requests are fetched server-side and safe public destinations are checked before every request and redirect.

Server Proxy

Pages, stylesheets and common links are routed through the server.

Safety Layer

Redirect Handling

📦

Limits

GET-only, standard HTTP/HTTPS ports, 5 MB response cap and bounded redirects.

🔒 SSRF-awareDNS resolution is validated and every redirect is revalidated.
📡 No arbitrary tunnelingThe endpoint only performs normal HTTP GET requests.
